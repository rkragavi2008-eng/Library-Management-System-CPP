# Library Management System (C++)

##  Description
This project is a simple Library Management System developed using C++. It helps manage books, members, and borrowing operations efficiently using file handling and object-oriented programming.

##  Features
- Add new books
- Display all books
- Search books by title or author
- Add members
- Issue books
- Return books

##  Technologies Used
- C++
- File Handling
- Object-Oriented Programming (OOP)

##  How to Run

1. Compile the program:
g++ library.cpp -o library

2. Run the program:
./library

##  Files Used
- books.txt → stores book details
- members.txt → stores member details
- records.txt → stores issued book records

## Outcome
This application allows efficient management of library operations including book addition, searching, issuing, and returning.
